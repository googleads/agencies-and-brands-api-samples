# [Agencies & Brands API Samples](//github.com/googleads/agencies-and-brands-api-samples)

This repository contains samples for the Agencies & Brands API. You can
reference these samples to better understand how you can use Google's client
libraries to make API calls with the Agencies & Brands API.

The code samples are organized by language, and run on the command line. You
can refer to the README.md file in the directory corresponding to your desired
language for usage instructions.

This project is intended for demonstration purposes only. It is not
intended for use in a production environment.

## Prerequisites

You must have an active Agency account in order to run the samples included in
this repository. If you run a sample that performs one or more write
operations, the outcome of those operations will be reflected in your account.
If you don't have an account, contact your Technical Account Manager to create
one.

We recommend that you familiarize yourself with the Agencies & Brands API to
better understand the operations demonstrated in these samples.

* [Agencies & Brands documentation](//developers.google.com/authorized-buyers/agencies-and-brands)
* [Agencies & Brands API reference](//developers.google.com/authorized-buyers/agencies-and-brands/apis/agenciesandbrands/reference/rest)
